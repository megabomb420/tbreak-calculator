# T-Break Calculator

Mobile-first, local-first PWA for THC tolerance-break planning. Deterministic
engines own every scientific/numeric output. No account, no network science,
no runtime AI in v1.

Version **0.6.0** — current-pattern duration question plus a full day-by-day
break outlook from Day 1 through the planning target. Duration is contextual
only: it does not change recommended ranges. The old “First weeks” result
block is replaced by the outlook, reused on Result, Plan Detail, and
open-ended tracking. Engines, bands, golden fixtures, and the iOS viewport
contract are unchanged.

Live PWA: https://megabomb420.github.io/tbreak-calculator/
